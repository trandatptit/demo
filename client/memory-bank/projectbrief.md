# Project Brief: FHeight Growth Client

## Project Overview

Vue 3 web application với Tailwind CSS, Vue Router, và Pinia state management.

## Core Requirements

1. Modern Vue 3 application với Composition API
2. Tailwind CSS cho styling
3. Vue Router cho navigation
4. Pinia cho state management
5. Vite làm build tool

## Tech Stack

-   **Framework**: Vue 3
-   **Build Tool**: Vite
-   **Styling**: Tailwind CSS
-   **Routing**: Vue Router
-   **State Management**: Pinia
-   **Language**: JavaScript

## Project Structure

```
client/
├── src/
│   ├── assets/          # Static assets
│   ├── components/      # Reusable components
│   ├── views/           # Page components
│   ├── router/          # Vue Router configuration
│   ├── stores/          # Pinia stores
│   ├── App.vue          # Root component
│   ├── main.js          # Entry point
│   └── style.css        # Tailwind directives
├── public/              # Public assets
└── memory-bank/         # Project documentation
```

## Development Commands

-   `npm run dev` - Start development server
-   `npm run build` - Build for production
-   `npm run preview` - Preview production build
